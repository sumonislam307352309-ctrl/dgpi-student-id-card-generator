# 🪪 Dhaka Govt. Polytechnic Institute - Student ID Card Generator

A lightweight, user-friendly, and responsive web application designed to generate, manage, and print official Student ID Cards for **Dhaka Govt. Polytechnic Institute (DGPI)**.

## ✨ Features

- **Live Preview:** Instant dual-side (Front & Back) card preview while typing.
- **Image Upload & Customization:** Upload student photo, institute logo, and official signatures.
- **Bilingual Support:** Switch seamlessly between **Bengali** and **English** languages.
- **Local Database (Storage & Search):** Save student records locally, search by Roll/Name, and load or delete data anytime.
- **QR Code Generator:** Automatically generates student QR codes containing essential credentials.
- **Print & Export Ready:** 
  - Download high-resolution print-ready A4 PDF sheets with standard cut-line borders.
  - Direct print support from the browser.
- **No Background Image Border:** Clean image presentation with exact aspect ratio.

---

## 🛠️ Tech Stack

- **HTML5 & CSS3**
- **JavaScript (ES6+)**
- **Tailwind CSS** (UI Framework)
- **html2canvas & jsPDF** (PDF Generation)
- **QRCode.js** (Dynamic QR Codes)
